# QuickCalc — Calculator & INR Expense Tracker

A two-in-one web utility built with **HTML5, CSS3, and JavaScript**, combining a keyboard-friendly calculator (with history) and an Indian Rupee (`₹`) daily expense tracker with budget progress and `localStorage` persistence.

## Live Demo
- **Live App:** `https://pribharti18.github.io/quickcalc-expense-tracker/`
- **Repository:** `https://github.com/pribharti18/quickcalc-expense-tracker`

## Key Features
- Standard and scientific calculator operations with keyboard input and history
- Option to send a calculated value straight into an expense entry
- Daily expense tracking in INR (`₹`) with category filtering, search, and budget progress bar
- Data saved in browser `localStorage` across sessions

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6+) & Browser `localStorage`

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any web browser.
